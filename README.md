# Odoo Apps: Contract

Odoo modules extending the `contract` module.

## Usage

Clone this repo into the Odoo addons directory.

```bash
git clone git@github.com:Mint-System/Odoo-Apps-Contract.git ./addons/contract
```

## Available modules

| Module | Summary |
| --- | --- |
| [sale_contract](sale_contract) | Additional contract fields on sale order. |
| [sale_contract_puzzle](sale_contract_puzzle) | Add fields to sale order contracts. |
