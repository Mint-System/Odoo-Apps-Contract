# Odoo Apps: Contract

Odoo modules extending the `contract` module.

## Usage

Clone this repo into the Odoo addons directory.

```bash
git clone git@github.com:Mint-System/Odoo-Apps-Contract.git ./addons/contract
```

| Module | Summary |
| --- | --- |
