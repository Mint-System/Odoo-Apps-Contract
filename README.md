# Odoo Apps: Contract

Odoo modules extending the `contract` module.

## Usage

Clone this repo into the Odoo addons directory.

```bash
git clone git@github.com:Mint-System/Odoo-Apps-Contract.git ./addons/contract
```

## Available modules

| Module | Summary |
| --- | --- |
| [contract_format_date_marker](contract_format_date_marker) |         Format date from contract markers in invoice line. |
| [contract_invoice_cash_rounding_default](contract_invoice_cash_rounding_default) |         Apply default cash rounding when create invoice from contract. |
| [subscription_oca_section](subscription_oca_section) |         Add notes and section to subscription line table. |
